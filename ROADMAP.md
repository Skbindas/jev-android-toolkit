# Roadmap

Jev Android Toolkit is intentionally focused on safe, bounded semantic decisioning for Android applications.

## Near term

- Publish stable Maven artifacts with complete POM metadata.
- Add reproducible integration fixtures for each decision module.
- Expand the Compose playground with production-shaped examples.
- Add more verification and abstention test cases.
- Document backend-mediated authentication and API-key handling.

## Medium term

- Publish versioned API documentation.
- Add benchmark fixtures with reproducible methodology and no synthetic marketing claims.
- Add optional integration tests for the live Jev transport.
- Improve contributor examples and issue triage.

## Long term

- Stabilize the public API toward a 1.0 release.
- Evaluate additional Android decision modules based on real community requests.
- Track compatibility across supported Kotlin, AGP, Gradle, and Android API versions.

Roadmap items are targets, not promises. Security, correctness, and reproducibility take priority over feature count.
