# Discoverability strategy

This project uses repository metadata, descriptive README language, public documentation, releases, and real external adoption rather than keyword stuffing.

## Primary concepts

- Jev Android Toolkit
- Android Jev
- Kotlin Jev
- TypeSafe Jev
- Android decision modules
- AI decision engine for Android
- semantic decision making
- UGC moderation
- notification routing
- semantic search reranking
- paywall decisioning
- verification and confidence gates

## Search integrity

Every primary term in the README maps to an actual feature, module, API, or architectural concept in this repository.

Do not add unrelated keywords solely to increase impressions.

## Growth signals to build next

1. Publish tagged releases with migration notes.
2. Publish a small Maven-compatible artifact once the public API is stable.
3. Add a real demo application and screenshots.
4. Add integration examples showing production-safe backend mediation.
5. Encourage external users to report issues and submit focused PRs.
6. Add links from genuine technical articles, demos, and projects that actually use the toolkit.
7. Keep commit history, tests, benchmarks, and documentation reproducible.

GitHub search can match repository name, description, topics, and README content. Topics should therefore be specific and truthful. Search placement and Google results cannot be guaranteed by metadata alone.
