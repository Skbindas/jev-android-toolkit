# API reference — 0.1.0

This is the versioned public API snapshot for Jev Android Toolkit 0.1.0. It documents the stable surface intended for consumers; implementation details may change in later releases.

## `decision-core`

- `JevRequest` — typed model name, state, and question map.
- `JevResponse` — typed model name, answer map, and optional token usage.
- `JevQuestions.choice(...)` — builds a bounded choice question.
- `JevQuestions.score(...)` — builds a numeric 2–10 scoring question.
- `JevQuestions.noul(...)` — builds a boolean-style probability question.
- `DecisionPolicy` — enforces confidence, margin, probability, and score-contract gates.
- `Decision.Accepted` — a policy-approved typed result.
- `Decision.Abstained` — an explicit fallback when evidence is insufficient or malformed.

## `jev-client`

- `JevTransport` — suspendable transport seam for live or fake implementations.
- `JevClient.evaluate(...)` — sends one state with one or more typed questions.
- `JevClient.choice(...)`, `score(...)`, `noul(...)` — typed convenience methods.
- `HttpJevTransport` — server-side HTTP transport for the TypeSafe System One endpoint.

## `decision-modules`

- `PaywallDecider` — `SHOW`, `DEFER`, or `SUPPRESS`, with entitlement bypass.
- `ModerationDecider` — `ALLOW`, `REVIEW`, or `REJECT`.
- `NotificationRouter` — `DELIVER`, `DIGEST`, or `SUPPRESS`, with high-priority bypass.
- `SemanticReranker` — bounded scoring for at most 50 candidates per call, preserving abstentions.
- `VerificationDecider` — semantic verification guarded by confidence.

## Stability rules

- Model output is treated as untrusted input to deterministic policy code.
- Unknown choices and malformed numeric values abstain.
- Irreversible operations remain outside Jev.
- Consumers should pin a released version rather than a moving development branch.
